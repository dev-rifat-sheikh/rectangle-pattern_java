# Rectangle Pattern Java

A simple Java program to print a rectangular pattern using loops.

## Description

This Java application prints a rectangle made of characters (e.g., `*`) using nested loops.  
It’s a beginner-level console program to practice **nested loops** and **pattern printing** in Java.:contentReference[oaicite:0]{index=0}

## Features

- Prints a rectangle pattern
- Uses nested loops for rows and columns
- Easy to understand and extend
